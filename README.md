# Texture Mapping Project

Final Project for the Computer Graphics course at the University of Haifa.
This repository contains my implementation of Texture Mapping in the software renderer developed during the course.
The project includes texture mapping using UV coordinates, integration with Phong shading, and a comparison between Nearest Neighbor and Bilinear Filtering.
